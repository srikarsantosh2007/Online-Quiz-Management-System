About Online Quiz Management System

Overview

The Online Quiz Management System is a web-based application designed to facilitate the creation, management, and administration of online quizzes. It provides a user-friendly interface for both administrators and students.

For Administrators

  • Create and manage quizzes with multiple choice questions
  • Add, edit, and delete questions
  • Manage student accounts
  • Assign quizzes to students
  • View detailed reports and analytics
  • Track student performance over time

For Students

  • Register and create personal accounts
  • View available quizzes
  • Take quizzes with timed sessions
  • Receive instant results and feedback
  • View quiz history and previous attempts
  • Update personal profile information

Technology Stack

Backend:
  • Python 3
  • Flask Framework
  • SQLite Database
  • SQLAlchemy ORM
Frontend:
  • HTML5
  • CSS3
  • Bootstrap 5
  • Jinja2 Templating

Features

Secure Authentication

Password hashing and session management for secure access.

Real-time Scoring

Instant feedback and score calculation upon quiz submission.

Responsive Design

Mobile-friendly interface accessible from any device.
